## Student Management System

An intuitive, feature-rich desktop application built with Python and Tkinter for real-time student record management, performance tracking, and grade calculation. Engineered with robust file handling, dynamic search/filter capabilities, and persistent cross-platform environment support. The application demonstrates desktop application design, safe file I/O operations, string manipulation, error handling, and persistent storage management.

## Features

* Interactive graphical user interface (GUI) built with Tkinter
* Seamless Light Mode and Dark Mode theme toggling
* Multi-criteria live search and dynamic student record filtering
* Persistent data storage using JSON format to automatically save and load student data
* Real-time performance calculations for marks, percentages, letter grades, and pass/fail status
* Full transaction CRUD capabilities with edit, delete, and list clear functions
* Standalone executable compatibility using reflection and path management

## Technologies Used

* Python 3.x
* Tkinter (Graphical User Interface Library)
* JSON (Data Storage Format)
* os & sys (File System and Path Management)

## What I Learned

* GUI Development & Design: How to build clean, responsive desktop interfaces using Tkinter widgets, layout managers (Grid & Pack), and dynamic theme switching algorithms.
* Data Persistence & State Management: Implementing file I/O operations using the json library to save, load, and sync local application state seamlessly across sessions.
* Algorithmic Logic & Data Manipulation: Building custom search routines, string normalization techniques, automated grade calculators, and standard lambda sorting functions.
* Error Handling & Input Validation: Managing edge cases, preventing invalid data entry using custom dialog alerts, and ensuring robust exception handling using try-except blocks.

## How to Use

1. Ensure Python 3.x is installed on your computer.
2. Clone or download this repository to your local machine.
3. Open your terminal or command prompt and run python main.py.
4. Type your student details in the input boxes (Name, Roll Number, Course, and Marks), then click Add Student.
5. Use the search bar or sorting buttons to filter student records dynamically.
6. Click Light Mode / Dark Mode to toggle application themes instantly.
7. Select a student record from the list to edit its details, modify their marks, or delete them from the database.
